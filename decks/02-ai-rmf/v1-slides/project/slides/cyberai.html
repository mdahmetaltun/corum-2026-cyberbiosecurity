This is the bridge we promised yesterday. The Cyber AI Profile is a CSF 2.0 community profile for AI, with three focus areas: secure, defend, thwart. It is a preliminary draft, so cite it as such. For an institution, the practical message is that you extend the CSF programme you already have.
