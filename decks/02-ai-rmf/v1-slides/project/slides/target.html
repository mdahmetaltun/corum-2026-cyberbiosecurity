AI as the target · NIST AI 100-2 E2025

The model is also an asset to attack

1

Data poisoning

Corrupt the training or reference data so the model learns the wrong thing

2

Prompt injection

Hide instructions in a document or web page the assistant reads

3

Supply chain

Tampered model weights, packages or plug-ins from third parties

4

Privacy attacks

Infer or extract sensitive training data, such as patient records

So far the AI was the source of risk. Here it is the target. NIST's adversarial machine learning taxonomy names the classes of attack; four are enough for a lab audience. Prompt injection deserves a minute: an assistant that reads a supplier's PDF or a web page can be instructed by text hidden inside it. Anyone connecting an assistant to email or files should know this.
